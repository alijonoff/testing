# TDD Exercises (Java 17 + Maven + JUnit 5)

This project contains solutions for several Test-Driven Development (TDD) practice exercises implemented in **Java 17** with **Maven** and **JUnit 5**.

## ✅ Implemented Exercises

1. **FizzBuzz**
2. **Leap Year Calculator**
3. **String Calculator**
4. **Prime Number Checker**
5. **Password Validator**
6. **Roman Numeral Converter**
7. **Bowling Game Scorer (Advanced)**

Each exercise has:
- Production code in `src/main/java`
- Unit tests in `src/test/java`

---

## 🧰 Tech Stack

- Java **17**
- Maven
- JUnit **5**
